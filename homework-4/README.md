## 📋 Overview

A 4-agent bug-fixing pipeline operating on a Python CLI Budget Tracker app. The pipeline verifies bug research, fixes bugs, checks security, and generates unit tests — all via a single shell command.

```
flowchart LR
  A[Research Verifier] --> B[Bug Fixer]
  B --> C[Security Verifier]
  B --> D[Unit Test Generator]
```

---

## 🤖 The 4 Agents

| Agent | File | Model | Justification |
|-------|------|-------|---------------|
| Research Verifier | `agents/research-verifier.agent.md` | `claude-opus-4-8` | Cross-referencing every file:line claim against source requires deep reasoning and long-context accuracy; Opus 4.8 handles multi-file verification reliably |
| Bug Fixer | `agents/bug-fixer.agent.md` | `claude-sonnet-4-6` | Structured execution of a defined plan (read → edit → test) is a routine task; Sonnet 4.6 is fast and cost-effective for this workflow |
| Security Verifier | `agents/security-verifier.agent.md` | `claude-opus-4-8` | Threat modeling, severity judgment, and catching subtle vulnerabilities demand the strongest reasoning model |
| Unit Test Generator | `agents/unit-test-generator.agent.md` | `claude-sonnet-4-6` | Generating pytest scaffolding for known, clearly-defined changes is a routine task; Sonnet 4.6 produces idiomatic code efficiently |

## 📱 Mini App: Budget Tracker CLI

A minimal Python CLI for tracking personal expenses, backed by SQLite.

**Commands:** `add`, `list`, `search`, `summary`

**Seeded defects (before pipeline):**

| ID | Type | File | Function | Description |
|----|------|------|----------|-------------|
| BUG-001 | Logic | `src/calculator.py` | `average_spending` | `ZeroDivisionError` when transaction list is empty |
| BUG-002 | Logic | `src/calculator.py` | `calculate_balance` | Off-by-one: `transactions[1:]` skips the first transaction |
| SEC-001 | Security | `src/storage.py` | `search_transactions` | SQL injection via f-string interpolation in SQL query |

**After pipeline:** all 3 defects fixed, 8 unit tests passing.

## 🏃 Quick Start

```bash
cd homework-4

# Run tests
python3 -m pytest tests/ -v

# Use the app
python3 src/budget.py add 50.00 food "lunch at cafe"
python3 src/budget.py add 120.00 transport "metro pass"
python3 src/budget.py list
python3 src/budget.py search "cafe"
python3 src/budget.py summary

# Run the full pipeline (requires claude CLI + ANTHROPIC_API_KEY)
bash run-pipeline.sh
```
